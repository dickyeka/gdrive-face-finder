## HIGH Priority — Hard Gate Violations

1. **[HIGH] [R-02 — Copywriting (Em Dash Forbidden)]** `templates/index.html` (lines 6, 142, 149, 426–428, 650): Em dash characters (`—`) appear in the `<title>`, sensitivity slider labels, and JS tolerance descriptions instead of commas, colons, or parentheses.
2. **[HIGH] [R-03 — Mobile Responsiveness & Tap Targets]** `templates/index.html` (lines 87, 204, 211, 220–231, 561, 864–871): Multiple interactive buttons (webcam trigger, HUD toggle, category filter pills, thumbnail remove buttons, card action buttons) are smaller than the 44×44px minimum tap target.
3. **[HIGH] [R-25 — Color Contrast (WCAG AA)]** `templates/index.html` (lines 107, 135, 147, 187, 742, 795): Helper captions, slider min/max labels, and secondary text use `text-slate-500` (`#64748b`) at `10px–11px` on dark `slate-900`/`slate-950` backgrounds (~3.7:1–4.1:1 ratio, below the 4.5:1 WCAG AA minimum for small text).
4. **[HIGH] [R-27 — UI States (Empty, Loading, Error)]** `templates/index.html` (lines 466, 630, 666, 699, 770): Form validation, webcam errors, and scan failures use blocking browser `alert()` popups instead of an inline error state with a clear recovery action, and the initial view before any scan has no explicit empty state explaining the next step.
5. **[HIGH] [R-32 — Keyboard Accessibility & Focus Indicators]** `templates/index.html` (lines 95, 133, 759, 845): The upload `#dropzone` (`<div>`), gallery photo cards (`<div>`), and table rows (`<tr>`) use mouse-only `onclick` handlers without `tabindex="0"`, `role="button"`, or `Enter`/`Space` keyboard handlers, and `#folderUrl` strips the default focus ring (`focus:outline-none`) without a high-visibility replacement on all controls.
6. **[HIGH] [R-34 / R-21 — Theme Support (Hardcoded Dark Mode)]** `templates/index.html` (lines 13, 34): The entire interface is hardcoded to a dark slate theme with no working light/dark theme toggle or documented product-level justification in `DESIGN.md`.
7. **[HIGH] [R-37 — Design Direction Required]** `templates/index.html` (project root): No `DESIGN.md` or declared `ENERGY / RHYTHM / MOTION` dials exist for the interface, nor is the UI labeled as a draft without direction.

## MEDIUM Priority — Purpose-Gate Violations

8. **[MEDIUM] [R-01 — Color & Gradients (Generic Blue-Cyan-Indigo Gradient)]** `templates/index.html` (lines 13, 40, 66, 88, 156, 185, 319): Uses the default AI blue-cyan-indigo gradient across the hero headline, navbar icon, primary CTA button, webcam button, and progress bar, plus a full-page dark radial glow background without a written hierarchy purpose.
9. **[MEDIUM] [R-04 — Decorative Icons & Symbols]** `templates/index.html` (lines 41, 226, 238, 650, 766, 804): Uses a generic smiley-face SVG as the navbar brand icon and scatters decorative star symbols (`★`) across filter tabs, section badges, card pills, and table rows.
10. **[MEDIUM] [R-06 — Generic AI Typography]** `templates/index.html` (lines 82, 126, 248, 257): Uses wide-tracked uppercase labels (`uppercase tracking-wider`) on form and table headings and applies `JetBrains Mono` broadly across non-code UI elements without a documented typographic rationale.
11. **[MEDIUM] [R-09 — AI Capsule Badges]** `templates/index.html` (lines 47–49, 304–307): Uses pill-shaped capsule badges with translucent backgrounds, thin borders, and pulsing dots (`YuNet + ArcFace 512-d Biometrics` in the header and `Biometric Sensor Active` in the modal) as decorative tech labels.
12. **[MEDIUM] [R-10 — Excessive Glassmorphism]** `templates/index.html` (lines 37, 74, 167, 263, 291, 327, 352, 372, 851): Applies `backdrop-blur-*` simultaneously across 9+ surfaces (navbar, search card, progress card, table card, modals, badges, and gallery pills), exceeding the 1–2 element dose cap.
13. **[MEDIUM] [R-12 — Overly Soft Shadows]** `templates/index.html` (lines 40, 74, 156, 167, 211, 263, 292, 845): Applies large elevation shadows (`shadow-2xl`, `shadow-xl`, `shadow-lg`) to almost every container and button on the page without a written elevation hierarchy.
14. **[MEDIUM] [R-13 — Glow Everywhere]** `templates/index.html` (lines 40, 88, 156, 211, 221, 315, 814, 821–825): Applies colored glows (`shadow-cyan-500/25`, `shadow-emerald-600/20`, `shadow-[0_0_25px_...]`, glowing landmark dots) across buttons, cards, badges, and overlays simultaneously instead of reserving glow for at most 1–2 focal elements.
15. **[MEDIUM] [R-19 — Endless Pulses and Loops]** `templates/index.html` (lines 54, 170, 206, 302, 328): Runs perpetual `animate-pulse` and `animate-ping` loops on status dots in the header, HUD toggle button, and modal headers even when no live state transition is occurring.
