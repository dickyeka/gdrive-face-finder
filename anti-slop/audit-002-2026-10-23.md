## HIGH Priority — Hard Gate Violations (`R-03 — Mobile Responsiveness`)

1. **[HIGH] [R-03 — Sticky Header Wraps & Steals Mobile Viewport]** `templates/index.html` (lines 150–179): On narrow viewports (`320px–390px`), keeping `#engineBadge` (`YuNet + ArcFace 512-d`) inline beside the brand title and `#themeToggleBtn` forces the `sticky top-0` header to wrap into a tall two-row bar that consumes excessive vertical screen space while scrolling.
2. **[HIGH] [R-03 — Thumbnail Grid Crowding & Tap Target Overlap on Phones]** `templates/index.html` (lines 252, 726–765): `#thumbnailsTray` uses `grid-cols-3` at the smallest mobile widths, making each square thumbnail ~`78px` wide so the `44×44px` remove button overlaps most of the thumbnail and sits too close to adjacent thumbnails.
3. **[HIGH] [R-03 — Fixed-Pixel Webcam Guide Overflows Mobile Video Frame]** `templates/index.html` (lines 456–466): Inside `#webcamModal`, the oval alignment guide uses fixed dimensions `w-44 h-60` (`176px × 240px`), which exceeds the height of the `aspect-[4/3]` video container (~`195px` tall on a `320px–360px` phone) and clips against the container edges.
4. **[HIGH] [R-03 — Lightbox `vh` Units & Floating Arrow Collision on Mobile]** `templates/index.html` (lines 487–528): `#lightbox` uses `max-h-[92vh]` / `max-h-[68vh]` instead of dynamic viewport height (`dvh`), causing mobile browser toolbars to clip the bottom metrics card, while the floating `left-4`/`right-4` prev/next buttons cover the photo edges on phone screens.
5. **[HIGH] [R-03 — 6-Column Desktop Table Forces Horizontal Scroll on Mobile]** `templates/index.html` (lines 418–435, 979–1015): The match table renders all 6 columns (`#`, `Photo File`, `Category`, `Faces Detected`, `ArcFace Sim`, and side-by-side `View` + `Download RAW` buttons) at every width, forcing sideways scrolling on phones instead of reflowing into a mobile card/stacked row layout below `sm` (`640px`).
6. **[HIGH] [R-03 — Desktop-Sized Padding & Spacing Carried Unchanged to Mobile]** `templates/index.html` (lines 182, 211, 306, 320, 413, 442): Main container (`py-8 space-y-8`) and section panels (`p-6`, `p-8`) retain desktop padding on mobile instead of stepping down to a mobile register (`py-5 sm:py-8`, `p-4 sm:p-6`, `space-y-5 sm:space-y-8`).
7. **[HIGH] [R-03 — Two-State Form Grid Crammed at Tablet Portrait Widths]** `templates/index.html` (lines 214, 393, 407): `#scanForm` switches to 2 columns at `md` (`768px`), cramming the reference dropzone and Drive URL/slider column on `768px–900px` tablets instead of breaking at `lg` (`1024px`) where both columns have room to breathe.
8. **[HIGH] [R-03 — Hover-Only Interactions Lack Touch `:active` Feedback]** `templates/index.html` (lines 225, 375, 379, 991, 1072): Interactive buttons, filter tabs, photo cards, and table rows define `:hover` states (`hover:opacity-90`, `group-hover:scale-105`) without `:active` touch feedback (`active:scale-[0.99]` or `active:opacity-80`) for mobile tap confirmation.
9. **[HIGH] [R-03 — Action Bar & Filter Buttons Crowd on Narrow Screens]** `templates/index.html` (lines 347–382): The results action bar (`Biometric HUD` + `Download All Matches (.ZIP)`) and category filter buttons wrap unevenly on `< 480px` phones instead of stretching cleanly to full width on mobile and auto-width on `sm+`.
